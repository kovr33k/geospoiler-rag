# GeoSpoiler RAG

Поисковая база по постам Telegram-каналов: посты превращаются в нормализованный материал, затем в карточки Enriched v2, по которым идёт поиск и ответы.

## Язык

### Путь поста

**Курсор канала**:
Номер последнего поста канала, после которого заливка продолжится при следующем прогоне.
_Не использовать_: чекпоинт, last id

**Пост «только изображение»**:
Пост, в котором из содержимого есть только изображения, а в тексте нет ни букв, ни цифр после удаления ссылок, хештегов и эмодзи.
_Не использовать_: пустой пост, картинка без подписи

### Исходы обработки

**Исход обработки**:
То, чем закончилась обработка поста или канала на одном этапе пути, если пост не стал готовой карточкой Enriched v2.
_Не использовать_: статус, результат, пропуск

**Журнал исходов**:
Перечень незакрытых исходов обработки; исход покидает журнал, когда пост позже обработан успешно.
_Не использовать_: лог пропусков, лог ошибок

**Ожидает повтора**:
Исход, который следующий прогон заливки повторит без участия человека.

**Ожидает ревью**:
Исход, для которого нужен человек в очереди ревью.

**Ошибка обработки**:
Исход, при котором выбранная обработка не удалась и сама не повторится.
_Не использовать_: сбой, фейл

**Пропуск по политике**:
Исход, при котором содержимое намеренно не обрабатывалось по правилам заливки; это не ошибка и не доказательство того, что содержимое неважно.
_Не использовать_: пропущено, игнор
