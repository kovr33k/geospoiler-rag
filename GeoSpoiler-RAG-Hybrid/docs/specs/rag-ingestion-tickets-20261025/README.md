# Задачи по спецификации RAG

Дата: 25 октября 2026 года.

Статус: разбивка T1–T9 подтверждена пользователем и опубликована по `$to-tickets` в приватном `kovr33k/geospoiler-rag`. Созданы девять issues №2–10 с меткой `ready-for-agent`; проверены тексты и все 13 нативных блокирующих связей. Родительская [спецификация №1](https://github.com/kovr33k/geospoiler-rag/issues/1) осталась открытой, её тело, заголовок, метки и комментарии не изменялись.

T1–T9 ниже — идентификаторы согласованного проекта разбивки; рядом указаны фактические номера GitHub. Реализация задач ещё не запускалась.

Работа ограничена RAG. Luna, профиль `luna`, `xhigh`, полнота контекста вопросов и все остальные проекты сохраняются. Изменение AGENTS.md сверх утверждённой настройки в эти задачи не добавлялось.

1. **[#2: Перенести актуальный RAG в main нового приватного репозитория](https://github.com/kovr33k/geospoiler-rag/issues/2)** — T1.

   **Блокируется:** нет — можно начать сразу.

   **Результат:** В новом репозитории появляется проверенный актуальный проект, который можно получить и запускать; локальная история и незавершённые правки сохраняются.

   [Локальная копия опубликованного текста](01-source-migration.md).

2. **[#3: Проверять актуальный RAG полным pytest и Ruff в CI Windows и Linux](https://github.com/kovr33k/geospoiler-rag/issues/3)** — T2.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** CI нового репозитория проверяет реальный проект целиком и показывает достоверный результат для Windows и Linux.

   [Локальная копия опубликованного текста](02-complete-ci.md).

3. **[#4: Загружать уверенно русский текст без модельного перевода](https://github.com/kovr33k/geospoiler-rag/issues/4)** — T3.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** Русский пост превращается в валидную индексируемую карточку без лишнего вызова перевода; иностранные и смешанные материалы сохраняют нужную обработку.

   [Локальная копия опубликованного текста](03-russian-translation-bypass.md).

4. **[#5: Обрабатывать партию с общим пределом в три LLM-вызова](https://github.com/kovr33k/geospoiler-rag/issues/5)** — T4.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** Независимые материалы обрабатываются одновременно, но суммарное число активных обращений к одному backend остаётся не выше трёх.

   [Локальная копия опубликованного текста](04-shared-llm-limit.md).

5. **[#6: Сохранять валидные карточки и YouTube-генерации при смене модели](https://github.com/kovr33k/geospoiler-rag/issues/6)** — T5.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** Будущая самостоятельная смена модельных настроек пользователем не вызывает массовую переработку пригодных карточек; реальные изменения и ошибки по-прежнему требуют обработки.

   [Локальная копия опубликованного текста](05-model-independent-reuse.md).

6. **[#7: Обогащать материал сразу после готовности нормализованного входа](https://github.com/kovr33k/geospoiler-rag/issues/7)** — T6.

   **Блокируется:** [#5](https://github.com/kovr33k/geospoiler-rag/issues/5).

   **Результат:** Первый готовый материал уже становится карточкой, пока следующие ещё нормализуются; прерывание и повторный запуск не теряют работу.

   [Локальная копия опубликованного текста](06-stream-ready-material.md).

7. **[#8: Скачивать и анализировать медиа только при зависимости текста от вложения](https://github.com/kovr33k/geospoiler-rag/issues/8)** — T7.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** Посты с самодостаточным текстом обходятся без обработки ненужных вложений; необходимые скриншоты, карты и записи пополняют карточку, а неопределённые вложения остаются честно неразобранными.

   [Локальная копия опубликованного текста](07-selective-media.md).

8. **[#9: Загружать в LightRAG только новые, изменённые и незавершённые документы](https://github.com/kovr33k/geospoiler-rag/issues/9)** — T8.

   **Блокируется:** [#2](https://github.com/kovr33k/geospoiler-rag/issues/2).

   **Результат:** Обычный повторный `load` переиспользует совпадающие успешно обработанные документы и не удаляет их для повторной вставки.

   [Локальная копия опубликованного текста](08-incremental-graph-load.md).

9. **[#10: Подтвердить полный рабочий цикл и завершить переход на новый RAG-репозиторий](https://github.com/kovr33k/geospoiler-rag/issues/10)** — T9.

   **Блокируется:** [#3](https://github.com/kovr33k/geospoiler-rag/issues/3), [#4](https://github.com/kovr33k/geospoiler-rag/issues/4), [#6](https://github.com/kovr33k/geospoiler-rag/issues/6), [#7](https://github.com/kovr33k/geospoiler-rag/issues/7), [#8](https://github.com/kovr33k/geospoiler-rag/issues/8), [#9](https://github.com/kovr33k/geospoiler-rag/issues/9).

   **Результат:** Новый репозиторий становится проверенной рабочей точкой для заливки и явной загрузки графа; прежние два RAG-репозитория сохраняются архивами.

   [Локальная копия опубликованного текста](09-verified-cutover.md).

## Порядок выполнения

- Сейчас доступна [задача №2](https://github.com/kovr33k/geospoiler-rag/issues/2): перенос исходников.
- После неё независимыми направлениями становятся №3, №4, №5, №6, №8 и №9.
- Потоковое обогащение №7 блокируется общим LLM-лимитом №5.
- Завершение перехода №10 зависит от №3, №4, №6, №7, №8 и №9. Общий лимит №5 входит транзитивно через №7.
- Метка `ready-for-agent` не отменяет блокировки. Брать в работу нужно только задачи, все блокеры которых завершены.
- Внешний запрет запуска Actions не мешает самостоятельным кодовым задачам после переноса, но не позволяет объявить завершённую итоговую приёмку. Общие платёжные настройки не меняются.

[Запись публикации](publication.json) сохраняет соответствие номеров, идентификаторы и результат проверки. Локальные Markdown-файлы — копии GitHub-задач, а не отдельный локальный tracker.
