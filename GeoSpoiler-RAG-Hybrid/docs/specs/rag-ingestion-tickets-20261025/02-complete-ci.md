## What to build

Настроить проверки актуального дерева нового репозитория: полный offline pytest, блокирующий Ruff и поддерживаемые среды Windows и Linux. Пользователь должен видеть успешный CI только после фактического выполнения проверок.

Работа ограничена GeoSpoiler RAG. Текущие Luna, профиль `luna`, `xhigh` и полнота контекста вопросов сохраняются. Остальные проекты и общие настройки аккаунта не меняются.

## Acceptance criteria

- [ ] CI работает с исходниками нового репозитория и проверяет соответствующую ему ревизию, а не старый снимок другого репозитория.
- [ ] Сборщик запускает полный штатный offline pytest, включая отдельные pytest-функции, которые не собирал прежний unittest.
- [ ] Нарушения Ruff завершают проверку ошибкой; режим безусловного успешного завершения не используется.
- [ ] Проверки Windows и Linux используют поддерживаемые проектом версии Python и изолированные временные данные.
- [ ] Результат подтверждает реально выполненные шаги; инфраструктурный запрет запуска Actions описывается отдельно и не объявляется зелёным CI или кодовой ошибкой.
- [ ] Ограничения оплаты, общие политики Actions и настройки остальных проектов не меняются ради запуска проверок.
- [ ] Проверку CI считают завершённой только после фактического успешного выполнения; при внешней блокировке кодовые задачи с зависимостью лишь от #2 могут продолжаться.
