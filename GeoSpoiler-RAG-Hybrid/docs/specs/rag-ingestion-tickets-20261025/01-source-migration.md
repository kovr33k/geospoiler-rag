## What to build

Создать в выбранном приватном репозитории новый исходный снимок текущего RAG с основной веткой `main`, без переноса старой Git-истории. Сопоставить опубликованный состав с фактической рабочей версией и сделать направление дальнейшей работы однозначным. Это перенос исходников, а не реализация ускорений.

Работа ограничена GeoSpoiler RAG. Текущие Luna, профиль `luna`, `xhigh` и полнота контекста вопросов сохраняются. Остальные проекты и общие настройки аккаунта не меняются.

## Acceptance criteria

- [ ] В приватном `kovr33k/geospoiler-rag` доступна ветка `main` с исходниками, тестами, документацией, согласованной спецификацией и применённой настройкой agent skills.
- [ ] Опубликованный снимок сверён с текущим RAG; имеющиеся локальные правки явно учтены при определении состава, ничего не потеряно и не включено в снимок незаметно.
- [ ] Свежая рабочая копия нового репозитория содержит проект и проходит применимые проверки исходного состояния; уже пригодные результаты не повторяются только из-за создания commit.
- [ ] Рабочие базы, исходные материалы, локальные секреты и runtime-данные сохраняются локально и не становятся частью исходного снимка.
- [ ] Текущая рабочая копия и её незавершённая работа сохраняются; старую Git-историю не переписывают и не удаляют.
- [ ] Для RAG задан понятный рабочий remote нового репозитория без изменения глобальной Git-конфигурации или привязок других проектов.
- [ ] Старые репозитории пока сохраняют доступность истории; окончательная архивация выполняется после общей проверки перехода в «Подтвердить полный рабочий цикл и завершить переход на новый RAG-репозиторий».
