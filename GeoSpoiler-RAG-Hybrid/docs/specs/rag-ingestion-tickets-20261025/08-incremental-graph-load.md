## What to build

Включить корректное переиспользование в обычном пути явной загрузки графа. Сопоставлять стабильную идентичность, подготовленное содержимое и состояние обработки до удаления; сохранять требуемые метаданные и принудительные операции.

Работа ограничена GeoSpoiler RAG. Текущие Luna, профиль `luna`, `xhigh` и полнота контекста вопросов сохраняются. Остальные проекты и общие настройки аккаунта не меняются.

## Acceptance criteria

- [ ] Новый документ добавляется, изменённый заменяется со стабильной логической идентичностью, совпадающий успешный переиспользуется.
- [ ] У переиспользованного документа отсутствуют повторные удаление, вставка и извлечение; обязательные метаданные источника продолжают обновляться.
- [ ] Наличие ID без успешного завершения и совпадающего содержимого не считается достаточным основанием для пропуска.
- [ ] Неуспешные, неполные и изменившиеся документы повторяются корректно.
- [ ] Явные force, rebuild и переработка после изменения правил извлечения остаются возможными.
- [ ] Не вводится автоматическое удаление графовых документов из-за отсутствия карточки в очередном обходе; текущий тестовый граф не обновляется без явной команды.
- [ ] Приёмка через `load` наблюдает операции внешней LightRAG-границы и сохранённую идентичность; обычный `run` остаётся отдельным.
- [ ] Существующие проверки manifest, provenance и целостности загрузки сохраняются.
