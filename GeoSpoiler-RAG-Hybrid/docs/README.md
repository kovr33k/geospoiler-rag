## Статусы требований

ТЗ миграции меняет размещение кода и данных, сохраняя действующие RAG-контракты. Рабочая Wiki должна оставаться выключенной. Принятая практическая проверка R26 касается query-time synthesis, fallback и YouTube-ссылок.

[R24](RELEASE_EVIDENCE_REVIEW_FIX_TZ_R24_20260829.md) сохраняет незакрытые замечания к publication/SQLite recovery и точку продолжения hardening. Владелец проекта принял эти риски 2026-09-10 и снял обязательный gate; findings не считаются исправленными. После этого официальный post-structure live smoke прошёл 10/10.

Исторические ТЗ и evidence-документы пока сохраняют адреса: release-инструменты и предыдущие отчёты могут ссылаться на точные имена. Их перенос не должен менять содержание старого доказательства. Папки architecture/operations/specs/archive служат навигацией; фактические перемещения фиксируются в карте миграции.
