# geospoiler

Канонический код приложения. CLI/UI вызывают подготовку материалов и формирование ответов. Общие модели находятся в contracts, настройки — в config.py, разрешение старых адресов данных — в paths.py. Прежние импорты оставлены совместимыми оболочками; новые модули импортируют geospoiler.
